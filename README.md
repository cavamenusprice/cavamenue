# CAVA Menu & Nutrition Guide (cavamenue.us)

Independent nutrition guide, pricing calculator, and allergen resource for CAVA Mediterranean restaurant menu.

## Features
- **Full Menu & Prices**: Bowls, pitas, mains, bases, dips, dressings, toppings, drinks, and desserts.
- **Nutrition Calculator**: Interactive calorie and macronutrient calculator.
- **Allergen & Gluten-Free Guides**: Comprehensive dietary breakdowns.
- **Privacy Policy**: AdSense, CCPA, GDPR, and cookie compliance.
- **SEO & Structured Data**: Dynamic sitemap, OpenGraph metadata, schema.org JSON-LD.

## Tech Stack
- Next.js (App Router)
- React / TypeScript
- Tailwind CSS

## Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
